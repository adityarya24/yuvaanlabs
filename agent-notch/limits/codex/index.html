Codex usage limits

Updated 4 November 2026. Limits change; the sources below have the current numbers.

Codex on a ChatGPT plan has a usage allowance measured over a five-hour window, and weekly limits may apply on top. Local work and cloud tasks come out of the same allowance.

How the limits work

  • Five-hour window. OpenAI gives estimates as "local messages per five-hour period" for plans like Plus. They are estimates, not fixed counts: bigger tasks use more.
  • Weekly limits. "Weekly limits may also apply."
  • Shared allowance. "Local messages and cloud chats share your plan's usage allowance."
  • Pro plans currently have no five-hour limit, per OpenAI's pricing page.

How to check it

  • In the Codex CLI, run /status during a session to see your remaining limits.
  • OpenAI also has a usage dashboard with your current limits and reset times.

Both work, but you have to stop and look. When Codex is one of several agents you're running, it's easy to find out you're out only when a task stops.

Keep it on screen instead

Agent Notch reads Codex's own rate-limit windows from the Codex sign-in on your computer and shows them as a ring. It labels each window by its real length (for example "5h session" and "Weekly") and shows the reset time when you hover.

Agent Notch Pro in taskbar mode on a Windows 11 laptop: one ring per agent, usage percent underneath.
