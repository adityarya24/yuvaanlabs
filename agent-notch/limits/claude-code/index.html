Claude Code usage limits

Updated 4 November 2026. Limits change; the sources below have the current numbers.

On a Pro or Max plan, Claude Code runs on two limits at once: a five-hour session limit and a weekly limit. Hitting either one stops you until it resets.

How the limits work

  • Five-hour session limit. When it fills up you wait for it to reset.
  • Weekly limit. A cap across the whole week, on top of the session limit.
  • Shared with Claude. Anthropic says these limits "are shared across Claude and Claude Code", so chatting in Claude and coding in Claude Code use the same allowance.
  • Max also has a separate weekly limit for some models.

How to check it inside Claude Code

Type /usage in a Claude Code session. It shows your plan usage limits, and on Pro, Max, Ultra, Team and Enterprise plans a breakdown of what counts against them. /cost and /stats open the same screen. Claude Code also warns you as you get close to a limit.

The catch: you only see it when you ask, inside one terminal. If you run several sessions, or Claude Code next to Codex or Antigravity, you end up typing /usage a lot.

Keep it on screen instead

Agent Notch reads the same usage Claude Code uses, from the sign-in already on your computer, and shows it as a ring: the session window and the weekly window, each with its reset time when you hover. Nothing goes to us; the request goes straight from your computer to Anthropic.
