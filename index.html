MindSync

Local-first MCP orchestration, persistent shared memory and automatic task routing for coding agents.

  • Published on PyPI as mindsync-ai
  • Runs on your machine, with one memory shared across agents
View on GitHub 
$ pip install mindsync-ai
$ mindsync setup --mode auto
$ mindsync doctor

# ask any agent what was decided last week
$ mindsync memory recall --project my-repo \
    --query "database migration decision"
